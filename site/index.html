AiST для компьютера

Ваш ассистент AiST в десктоп-приложении: работает с файлами, терминалом и кодом прямо на компьютере. Всё нужное внутри, ничего доустанавливать не нужно.

Загружаем сведения о последней версии…

macOS

Apple Silicon (M1 и новее). Образ .dmg: перетащите AiST в «Программы».

Скачать для macOS

Windows

Windows 10/11, 64-бит. Обычный установщик .exe.

Скачать для Windows

Первый запуск

  1. Откройте AiST. Появится окно «Добавьте ассистента AiST».
  2. Вставьте JWT-токен Agent API и ID ассистента из личного кабинета AiST, нажмите «Подключить».
  3. Готово: выбирайте рабочую папку и ставьте задачи. Ассистентов можно добавить в Настройки → Ассистенты.
На macOS при первом открытии система может сообщить, что приложение от неустановленного разработчика. Нажмите правой кнопкой на AiST в «Программах» → «Открыть» → «Открыть». Это нужно один раз.

Обновления

Приложение само проверяет новые версии при запуске и раз в несколько часов, скачивает их в фоне и предлагает перезапуститься. Все версии: страница релизов.
